# 📚 Anime Ebooks Hub - Netflix Style
A fully functional Netflix-inspired anime ebook website ready for GitHub Pages.

## ✨ Features
✅ Netflix-style dark theme design
✅ Full English / Tagalog language support
✅ Clickable cards open detailed info modal
✅ Working download button
✅ Real-time search function
✅ Trending & New Released sections
✅ Fully responsive for all devices
✅ Zero errors & clean professional code

## 🚀 How to Use
1. Create a new repository on GitHub
2. Upload all 4 files exactly as structured
3. Go to Repository → Settings → Pages
4. Select `main` branch and save
5. Your website will be live in 1-2 minutes!

## 📌 Adding More Ebooks
Edit `script.js` → add new entries inside the `animeData` array following the existing format.

## 📌 Important Note
All download links are set to `#` as placeholder. Replace them with your actual file links before publishing.
